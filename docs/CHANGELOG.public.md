# Changelog

## 1.0.0 — 2026-05-27

First public release of Radiant Play.

- **Radiant design system** — 70+ product-agnostic components: inputs, actions, feedback, overlays, data display, navigation, plus layout primitives (Horizontal, Vertical, View, Grid).
- **Design tokens** — colors, spacing, typography, radius, and shadows, consumed via tokens (no hardcoded values).
- **Sample prototypes** — a starter set demonstrating realistic data and component composition.
- **Getting started** — a designer-friendly guide and prototype scaffolding (`npm run new-prototype`).
