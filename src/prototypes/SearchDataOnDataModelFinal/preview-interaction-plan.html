Data preview interaction — build plan

SearchDataOnDataModelFinal · Split layout · 23 Sep 2026 · three directions, click-through in Settings, for stakeholder buy-in on one. Good cases only — trap/degrade cases deferred.

Constants — true in every direction

  • The scope dropdown in the preview panel always offers Model, every table, every join.
  • Panel presence is the user's: closed by default, stays open once opened, selection never auto-opens it.
  • Table/join drills use the existing loading treatment. Creation flows untouched. Combined layout and Test tab untouched.
  • Creation selects the created thing: drop a table → it's selected; make a join → it's selected. What "selected" does to the panel depends on the direction.

The three directions — a top-level switcher, Settings → Data preview

1Select to preview

Home is Nothing. Clicking a table or join previews it; clicking the canvas background returns to "Nothing selected". A Model button in the canvas actions (next to Find/zoom) gives the model a canvas route; the dropdown is the second route. Refresh fixed: Manual · Cached.

≈ today's shipped Split behavior + the Model CTA. The market-convention option.

2Model is homedefault

Grid defaults to the model. Clicking a table or join drills in; clicking the background zooms back out to Model. No Model CTA — the canvas is the way back. "Nothing selected" is unreachable once a table exists.

Sub-knobs — render only while direction 2 is selected:
  • Refresh: Auto | Manual — model changes while the model grid is showing. Auto re-queries immediately; Manual holds rows and shows "Model changed — Refresh" in the panel header. Default: Auto.
  • Re-entry: Cached | Fresh — returning to the model view (zoom out, reopen panel). Cached is instant from the last result (stale then defers to the Refresh knob); Fresh re-queries every return. Default: Cached. Fresh exists to demonstrate why Cached wins.
  • Second-door icons: Off | On — preview icons on cards/joins as an explicit door that also opens a closed panel. Default: Off.
3Explicit preview only

Home is Nothing. Preview icons on table cards and join badges are the only preview trigger — selection highlights on canvas but never touches the panel; background clicks are inert to the panel. The Model CTA is the model's preview icon; dropdown as always. Refresh fixed: Manual · Cached.

The teammate's proposal — selection and preview fully decoupled.
