The differentiator

AI readiness · 60s
On screen
S15AI-readiness check runs — pill on the canvas, three layers checking in sequence.
S16Findings panel, graded:
  • 6 columns with no description
  • acct_st — ambiguous name, no synonyms
  • Fan-out risk on the Jira join
  • Renewal Risk has no definition an LLM can reason from
Say
Here's the part nobody else in this market has an answer for.

A model can be perfectly correct and still be useless to an AI. If a column is called acct_st, if a join fans out, if a metric has no definition — the model is fine for a human and a coin-flip for an LLM.

Data Studio grades the model on whether an LLM can actually reason over it. Then it fixes what it finds.
On screen
S17Agent applies fixes one by one. Score climbs to green.
S18Publish. Let the score animate. This is the only place worth spending a real animation.

Waiting out the cacheCached at real scale this takes minutes. Staged live it's dead air. Cut away and return on the notification — that is the behaviour

Build order for the prototype

Three states carry the demo. Build these first and at the highest fidelity; the rest can be static.

  1. S3 — confidence-scored suggestions. The scores, and the reasoning on hover, are the proof that the agent reasoned rather than dumped a table list. A plain checkbox list kills the beat.
  2. S11 — the editable notebook line. If she can't actually change the filter and re-run it, "not a black box" is an unsupported claim.
  3. S16 — readiness findings. Named, specific findings. A generic "3 issues found" wastes the only capability with no competitive answer.

Confirm before rehearsal

  1. Audience. Written for field/sales. If customers are in the room, cut "nobody else in this market has an answer for" and soften "no data engineer in the loop."
  2. Who drives. Assumes the VP clicks and narrates. If an SE drives, the on-screen lane becomes their cue sheet — split it out before rehearsal.
  3. Emphasis. AI readiness gets the longest beat at 65 seconds, on the argument that it's the only capability with no competitive answer. If "no ETL" is the stronger message for this room, swap: give Model Cache the long beat and compress readiness to 30 seconds.
