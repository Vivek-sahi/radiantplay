2
Canvas — Table/Joins view
Current: bezier lines, no relation type shown, one table highlighted in blue.
Goal: show cardinality (1:1, 1:many, many:1) on connectors; remove highlight; show only table name + selected column count + line.
Reference patterns: Standard ERD tools (Lucidchart, dbdiagram.io) use crow's foot notation — the de-facto standard data people know. Modern BI semantic layers (Looker, Metabase) use labeled badges ("N:1", "1:N") with join type text. Analytics engineering tools (dbt docs, Lightdash) show join type + cardinality on hover. ThoughtSpot's own data model UI uses line-and-arrow with join type label. The goal here is glanceable — Sara sees the model shape at a glance, detail available on demand.
A — Pill badge on connector
Cardinality + join type as a pill badge at line midpoint. Explicit, friendly, no prior knowledge needed.
B — Crow's foot notation
Industry-standard ERD notation. Crow's foot = many, double bar = one. Data people read this instantly. Join key shown as small label below the line.
★ Recommended
Crow's foot is the universal language for data modeling. Any analytics engineer recognizes it without reading text. The join key below the line gives enough context for debugging without cluttering the diagram.
C — ∞ and 1 endpoint symbols
Friendlier alternative to crow's foot. ∞ on many-side, 1 on one-side. Join type as a small chip below. More approachable for non-data audiences.
D — Colored directed arrow
Arrow shows join direction (FK → PK). Color encodes join type: blue = LEFT JOIN, gray = INNER JOIN. Cardinality label above the line.
E — Plain line with click-to-expand detail
Line at rest shows nothing extra. Clicking reveals a floating join card. Cleanest canvas — detail on demand. Shown here in expanded state.
F — ThoughtSpot-style: orthogonal connector + join icon + fan
Based on reference image. Right-angle connector lines. Join icon (chain link) floats at midpoint. Fan lines (3 spreading lines) indicate "many" at the exit point. One-side is a clean flat entry.
★ Explore
Based on the ThoughtSpot data model reference. Key elements: (1) right-angle connectors instead of bezier curves — cleaner, grid-aligned; (2) join icon at midpoint makes the relationship explicit without text; (3) fan lines at the "many" exit are immediately readable. The flat entry on the "one" side needs no additional indicator. This is the closest to the reference pattern and feels native to ThoughtSpot's visual language.
