Claude setup and skills

A one-time setup to get Radiant Play running in the Claude desktop app, plus the commands that help you build prototypes.
Time ~10 minutes
Steps 5 steps
Requires Claude app + Galaxy
↻ Already have the project on your machine? Open its folder in the Code tab and run /rp-sync-upstream to get the latest components and commands. Update library →
Before you start

What you need

No API key, and nothing to install in the terminal
  • 1 A Galaxy account and your own fork. Your ThoughtSpot login works. Make sure you can see the Radiant Play repo and that you've forked it. The forking guide covers how.
  • 2 The Claude desktop app. Download it from claude.ai/download (Mac and Windows) and sign in with your ThoughtSpot account.
  • 3 Node.js 22 or newer (20.19+ also works). If it's missing or too old, Claude tells you when you first start the project; install the LTS version from nodejs.org.
1

Open the Code tab

Pick a folder where your copy of the project will live

Open the Claude app and click Code at the top. Start a new session and choose a folder to work in. ~/Documents is fine; the project goes inside it.

2

Clone your fork

One time only. Claude downloads the project for you

Paste your fork's URL into the chat and ask Claude to clone it:

Claude chat
Clone https://galaxy.corp.thoughtspot.com/YOUR-USERNAME/radiantplay.git here

Claude downloads the project into a radiantplay folder.

⚠️ Galaxy asks you to sign in? Run the clone in the app's terminal panel instead, so you can type your login: git clone https://galaxy.corp.thoughtspot.com/YOUR-USERNAME/radiantplay.git
3

Open the project

Always open the radiantplay folder from now on

Start a new session and choose the radiantplay folder. Claude reads the project's CLAUDE.md when the session starts, so it already knows the Radiant components, tokens and conventions.

ℹ️ Open the radiantplay folder itself, not the folder above it. Otherwise the /rp- commands won't show up.
4

Start it up

Do this each time you come back to the project

Type this in the chat:

Claude chat
Start the dev server
# The first time, Claude installs the project's packages too (about a minute)

The app opens a preview pane that updates as Claude makes changes. Two URLs to know:

URL What's there
localhost:5173 The Radiant DS browser: components and tokens
localhost:5173/playground Your prototypes
5

Build your first prototype

Scaffold it, then describe what you want
Claude chat
/rp-new-prototype SettingsPage
# Starts with a capital letter, no spaces

Then describe what you want in the same chat, or drag in a screenshot and say "Recreate this using Radiant components". Claude builds it and checks it in the preview.

🎉 You're set up. Use the slash commands below to check, sync and share your work.
Slash commands

Slash commands

Type /rp- in the Code tab chat to see them all
/rp-new-prototype
Build
Start a new prototype
Scaffolds a prototype folder with the right structure and adds it to the gallery.
Usage: /rp-new-prototype SettingsPage, optionally followed by a short description of what it should do.
/rp-radiant-check
Build
Design system health check
Checks a prototype's components, tokens, content and layout, and shows the easy wins.
Supports focus: add an area, for example /rp-radiant-check SettingsPage content.
/rp-explore
Build
Step outside Radiant
Suspends the design system rules for a freeform direction. The rest of the prototype stays Radiant.
/rp-migrate-prototype
New
Geist font and dark mode
Moves your prototypes onto the Geist font and dark mode in one pass. Never commits.
/rp-sync-upstream
Sync
Pull in library changes
Shows what's new in the library, then asks before it merges anything into your fork.
/rp-coolify-deploy
Share
Get a live URL
Walks you through putting your fork on Coolify, with a URL that redeploys on every push.
/rp-project-canvas
Overview
See everything in one place
A local overview of your prototypes, branches and sites. Uses no AI tokens.
💬 No command for it? Just ask. "Capture a thumbnail for my prototype" or "Switch my prototype's AI to Sonnet" work too.
Library updates

Keeping your library current

New components, tokens and rules land upstream regularly
Claude chat
/rp-sync-upstream
# Shows what's coming, then asks before it merges

It previews new components, token changes, rule updates and any files that overlap with your work. When you say yes, it saves your in-progress work, merges, keeps your prototypes in registry-mine.ts, checks the build and puts your work back.

💡 When to sync: at the start of any new prototype sprint. If a new component matches what you're building, sync first so you don't build it twice.
⚠️ Older fork without /rp- commands? Type /sync-upstream instead. The old name still works, and the sync brings in the new commands.
Troubleshooting

If something goes wrong

Symptom Fix
Claude says Node.js or npm is missing Install the LTS version from nodejs.org, then ask Claude to start the dev server again.
The clone stops at a sign-in prompt Run the clone in the app's terminal panel so you can type your Galaxy login.
/rp- commands don't show up Check the session is open on the radiantplay folder, not its parent. On an older fork, run /sync-upstream.
The preview pane is blank Ask Claude to check the dev server logs and fix what it finds.
Optional

Prefer the terminal?

The same setup works with the claude command. Follow the install steps at claude.com/claude-code, sign in, then run it inside your radiantplay folder. Slash commands work the same way.

Terminal
$ cd ~/Documents/radiantplay
$ claude
